Questions before you order

How do I pay?

Place the order first, then pay directly by SEPA bank transfer or via PayPal (@AbhishekChaudhary454). Put your confirmation code in the transfer reference or PayPal note so we can match it.

When will it ship?

Each order is for one poster and one size. To get another size (or a different poster), place a separate order.
